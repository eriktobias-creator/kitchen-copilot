# Store files

Every `.md`, `.txt`, and `.csv` file in this folder is sent to the assistant as your store's source of truth, in filename order. Edit them on your Mac or phone, push, and the server picks up changes on the next question (no restart).

- Replace every `[fill in]` with your real numbers. Until you do, the assistant will say the store number isn't set.
- Add more files any time: station layout, opening/closing checklists, catering prep charts.
- Only put official Chipotle food-safety numbers here if you copied them from the official resource. The assistant trusts this folder over its general knowledge.
- Never put customer info or coworkers' personal info (phone numbers, addresses, schedules tied to names) in here.
